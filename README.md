# Gessi & Luca – Hochzeit

Website für den 10. Juli 2027. Geplante Adresse: https://ilnostrogiorno.congiu.ch

## Funktionen

- Sprachauswahl Deutsch / Italiano
- Locations: Klosterkirche Muri und Theater Casino Zug
- Menüplan
- Anmeldung mit Namen aller Gäste und Ernährungsangaben
- Foto-Upload für Gäste

## Infrastruktur

- Cloudflare Worker für Website und API
- Cloudflare D1 für Anmeldungen
- Cloudflare R2 für Fotos

Die Infrastruktur wird eingerichtet, bevor die Website veröffentlicht wird. Keine Gästedaten oder Zugangsdaten in dieses öffentliche Repository committen.
